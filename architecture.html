MCP — Model Context Protocol usage
How MCP is used in this project:
  • Claude Preview MCP — preview_start / preview_screenshot / preview_snapshot tools run the dev servers, navigate the live site, and capture visual proof of changes
  • Claude in Chrome MCP — browser automation, screenshot verification, DOM inspection during development
  • Scheduled Tasks MCP — ad-hoc task scheduling wired into Claude Code sessions
  • MCP Registry — connector discovery (search / suggest) for third-party integrations
  • settings.local.json allowlist — scopes which external domains / shell commands Claude Code agents may call (GitHub, Render health checks, CDN pings)
  • launch.json — MCP-readable server config; Claude Code reads this to know how to spin up local dev environments without manual CLI
